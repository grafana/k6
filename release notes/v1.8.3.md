k6 `v1.8.3` is here! This patch release includes:

- A browser fix for clicking a missing element handle
- Security updates for `golang.org/x/net` and `github.com/klauspost/compress`
- Updates to the JavaScript runtime and other dependencies

## Security updates

- [#6667](https://github.com/grafana/k6/pull/6667) Updates `golang.org/x/net` to `v0.62.0` and `github.com/klauspost/compress` to `v1.20.4` to address known vulnerabilities.

## Bug fixes

- [#6617](https://github.com/grafana/k6/pull/6617) Fixes a browser panic when `click()` is called on a missing element handle. The call now throws a catchable `TypeError`.

## Maintenance and internal improvements

- [#6650](https://github.com/grafana/k6/pull/6650) Updates Sobek and `regexp2`, and refreshes JavaScript compatibility and TC39 test expectations.
- [#6648](https://github.com/grafana/k6/pull/6648) Updates `github.com/andybalholm/brotli` to `v1.2.8`.
- [#6600](https://github.com/grafana/k6/pull/6600) Updates `github.com/grafana/k6provider` to `v0.5.1`.
- [#6601](https://github.com/grafana/k6/pull/6601) Updates `golang.org/x/crypto`, `x/sync`, `x/sys`, `x/term`, `x/text`, and `x/time`.
- [#6653](https://github.com/grafana/k6/pull/6653) Adjusts leak checks for Go tip on Windows.
- [#6649](https://github.com/grafana/k6/pull/6649) Updates the `v1.x` lint and CI workflows.
