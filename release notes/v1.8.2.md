k6 `v1.8.2` is here! This patch release includes:

- Security updates for gRPC, `golang.org/x/net`, `golang.org/x/crypto`, OpenTelemetry, and the Go toolchain

## Security updates

- [#6294](https://github.com/grafana/k6/pull/6294) Updates the Go toolchain directive to `go1.25.13`.
- [#6364](https://github.com/grafana/k6/pull/6364), [#6365](https://github.com/grafana/k6/pull/6365), [#6386](https://github.com/grafana/k6/pull/6386) and [#6387](https://github.com/grafana/k6/pull/6387) Update `google.golang.org/grpc` to `v1.83.2`.
- [#6352](https://github.com/grafana/k6/pull/6352) Updates `golang.org/x/crypto` to `v0.56.0`.
- [#6420](https://github.com/grafana/k6/pull/6420), [#6421](https://github.com/grafana/k6/pull/6421), and [#6422](https://github.com/grafana/k6/pull/6422) Update the OpenTelemetry OTLP trace exporters (`otlptrace`, `otlptracegrpc`, and `otlptracehttp`) to `v1.45.0`.
- [#6545](https://github.com/grafana/k6/pull/6545) and [#6553](https://github.com/grafana/k6/pull/6553) Updates `golang.org/x/net` to `v0.60.0`.

## Maintenance updates

- [#6285](https://github.com/grafana/k6/pull/6285) Updates GitHub actions and CI workflows
- [#6280](https://github.com/grafana/k6/pull/6280) Backports the Sobek update to `v1.x`, which also updates `Masterminds/semver` to `v3.5.0` and `dlclark/regexp2` to `v2`.
- [#6505](https://github.com/grafana/k6/pull/6505) Fixes the implicit `area` role test fixture in the browser module tests, so hidden image map areas are included.
